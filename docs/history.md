
# History disclosure

- The hypothesis (MPAS adds out-of-sample predictive value for trametinib sensitivity beyond mutation + lineage and a broader expression baseline) comes from the published MPAS paper (Wagle et al. 2018, doi 10.1038/s41698-018-0051-4), not from an analysis by the author.
- That paper reports associations between MPAS and MEK-inhibitor sensitivity in a Genentech cell-line collection (gCSI); the author has read it.
- An earlier, separate project of the author (perturbation causal-direction work) ran analyses that are not used to derive this hypothesis.
- Author's disclosure (stated 2026-11-14): the author has never run an MPAS or other MAPK-signature versus drug-response analysis on DepMap, PRISM, GDSC or CTRP data.
- Phase 0 of this project used only identifiers, availability counts and per-variable descriptive statistics; no association with any drug response was computed.
